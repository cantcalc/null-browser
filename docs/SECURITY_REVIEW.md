- 기존 Git 기록 18개 commit을 gitleaks로 검사: 탐지 0건. 새 commit 및 공개 대상 파일은 push 전에 추가 검사합니다.
- 프로필·쿠키·로그·임시 QA 자료·설치 파일·인증서·환경 파일은 소스 업로드에서 제외합니다.
- 기존 개발 보고서는 현재 소스 트리에서 제외하되, 요청한 기존 커밋 기록은 보존합니다. 과거 기록에는 당시 개발 경로와 작성자 정보가 있을 수 있습니다.
- 최초 npm audit: critical 2 / high 6 / moderate 16. 호환 범위의 패치 업데이트 후 critical/high는 해소했습니다.
- 배포 의존성 `npm audit --omit=dev`: 보고된 취약점 0건.
- 개발/빌드 도구 전체에는 moderate 15건이 남습니다. 전이 의존성의 glob/minimatch 및 빌드 도구 관련 권고입니다. audit의 강제 수정은 빌드 도구를 과거 major 버전으로 바꾸므로 적용하지 않았습니다.
- 위 숫자는 검사 시점 npm advisory 기준이며 보안 인증을 뜻하지 않습니다. CI는 배포 의존성 high 이상을 차단합니다.
- Electron, Chromium 및 배포 JavaScript 의존성의 라이선스 고지를 설치본에 동봉합니다. 두 npm 패키지의 누락된 고지 원문/메타데이터는 `docs/licenses`에 출처와 함께 보완했습니다.
- 프로젝트 고유 소스는 사용자가 선택한 MIT로 제공합니다. 로고/아이콘은 MIT 소스 라이선스와 구분하는 프로젝트 브랜딩 리소스입니다.
- 확장 권한 회수 제한, 전체 확장 호환 미보장, macOS 배포 서명/공증 부재 및 Windows 서명 여부는 README/Release에 명시합니다.
