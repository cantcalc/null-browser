# NULL AI 구현·검증 보고서

2026-11-04 · macOS Apple Silicon · 개발 버전 **1.1.0-beta.1**

**판정: 기능 코드와 맥 미리보기 구현, 모의 API/실제 브라우저·실제 패키지 OS 암호화 검증까지 진행했습니다. 실제 AI 사용 완료 또는 안정판 준비 완료 판정은 아닙니다.** 유효 API 키가 없어 정상 AI 답변은 미검증입니다. 키체인은 테스트 도구의 실행 파일 직접 실행에서 실패했지만 일반 앱 실행 방식(LaunchServices)에서 암호화·재시작 복원까지 통과했습니다. 평문 저장이나 보안 속성 변경으로 우회하지 않았습니다.

## 1. 실제 구현한 기능

- Gemini / Groq / OpenRouter BYOK, 워크스페이스별 여러 제공자 연결·변경·삭제·테스트·모델 갱신.
- 공식 API/문서의 무료 모델 및 텍스트·이미지·도구 지원 필터. 지원 미확인/유료/만료 모델 실행 차단.
- 사용자가 정한 순서의 무료 한도 초과 전환. 별도 제공자 변경 동의, 인증/일반 네트워크/서버/크레딧 오류 전환 금지, 중복 실행 및 무한 재시도 제한.
- 우측 기본 AI 사이드바, 좌측 이동·너비 조절·재실행 복원, 스트리밍·Markdown·코드 블록/복사·중지·새 대화.
- 메인 프로세스 메모리 대화. 닫아도 작업/대화를 유지하고 다시 열 때 복원하며 종료 시 삭제.
- 동의 기반 현재 페이지/선택한 최대 3개 탭의 텍스트·제목·URL·구조·코드 참조, 선택 텍스트 우클릭 질문·설명·요약·번역.
- 입력/탐지된 민감 텍스트 마스킹, 페이지 변경 검사, JPEG 크기 제한, 미리보기 확인 후 이미지 전송. 지원하지 않는 모델 차단.
- 전용/현재 탭 에이전트. 검색·공개 URL·관찰 링크·읽기·스크롤·요소 ID 기반 클릭·입력, 중요/불확실 작업 승인, 로그인/페이지 변경 대기·재개·취소.
- 전역 최대 2개 작업, 동일 탭 잠금, 16개 모델 단계·10분 작업 제한, 승인 거부 반복 차단.
- 시크릿 AI 차단, 기존 데이터 경로·암호화 식별자·워크스페이스 세션·확장 시스템 유지.

## 3. 제공자별 연결 결과

| 제공자 | 구현/모의 검증 | 실제 공개 API 검사 | 유효 키 성공 |
| --- | --- | --- | --- |
| Gemini | 모델·무료/기능·이미지 요청·SSE·함수 schema·thought signature | 잘못된 키 거부 확인 | 미검증 |
| Groq | 모델·무료·스트리밍·도구·한도 전환 | 잘못된 키 거부 확인 | 미검증 |
| OpenRouter | 키 확인·0단가/추가 비용 필터·이미지/도구·0 가격 상한 | 잘못된 키 거부, 공개 모델 목록 HTTP 200 | 미검증 |

실제 OpenRouter 공개 목록의 이번 스냅샷은 454개 항목, 그중 입력/출력 0단가 항목 18개였습니다. 고정 목록이나 실제 계정 권한/전체 추가 비용 검증의 대체 자료가 아닙니다.

일부 공식 문서는 자동 HTTP 접근을 거부했습니다. 보수적인 검토본과 인증된 모델 API의 교집합만 임시 허용하며 검토본은 **2026-11-11 00:00 KST**에 만료합니다. 만료하면 재검토/갱신 없이 실행하지 않습니다.

## 4. 실제 AI 응답 테스트

**유효한 API 키가 제공되지 않아 실제 모델의 답변은 실행하지 못했습니다.** 실제 계정의 quota 도달/전환과 이미지 이해 품질도 미검증입니다.

모의 제공자 응답으로 실제 UI → preload → 검증된 IPC → vault → provider adapter → SSE → delta IPC → Markdown의 전 과정을 실행했습니다. 공개 API와 모의 transport를 분리했습니다. 제품에 개발자 공용 키/가짜 성공 응답/모의 endpoint 전환 설정을 넣지 않았습니다.

## 5. 사이드바 테스트

- 소스 실행과 맥 패키지에서 각각 좌/우 × 800×600, 1280×720, 1440×900의 **6개 배치** 검사.
- 페이지 native view와의 비겹침, 패널 overflow, 키보드 너비 변경, 닫기/재열기 확인.
- 제공자 키 입력창 3개, 제출 후 키 제거·원본 미반환, 모델 선택, 실제 UI 스트리밍/중지 확인.
- Markdown 코드 블록 표시, script/JavaScript 링크 차단 확인. 코드 복사 UI는 구현했으나 OS 클립보드 전체 형식 복원 검사는 수행하지 않았습니다.
- 응답 중 닫고 다시 열어 대화가 유지되는지, 실제 프로세스 재실행 후 대화/작업은 사라지고 설정/연결 metadata가 남는지 확인.
- 시크릿 버튼 미표시 및 실제 AI IPC 거부 확인.

소스 UI의 성공 응답 검사는 **모의 네트워크와 모의 OS cipher**를 사용했습니다. 맥 패키지 UI의 최종 검사는 **모의 네트워크 + 실제 OS safeStorage**입니다. 실행 방법과 crypto 여부를 검사 결과 JSON에 따로 기록했습니다. 패키지의 실제 프로세스 재시작 후 저장한 테스트 키를 복호화하여 모델 목록을 다시 조회했고, 파일에 평문이 없고 권한이 0600인지 검사했습니다.

## 6. 페이지 분석 테스트

실제 WebContentsView의 소유한 문서에서 다음을 확인했습니다.

- 보이는 텍스트·구조 수집, 입력값/숨김 DOM/편집 중 내용/스크립트/이메일 제외.
- 제어용 isolated world의 상태가 페이지 main world에 보이지 않음.
- JPEG 캡처 크기 제한과 마스킹된 입력 영역의 실제 픽셀 확인.
- 비밀번호/로그인 화면의 추출·캡처 차단.
- 변경된 요소 fingerprint로 과거 대상을 클릭하지 않고 일시정지.

선택/탭/이미지의 AI 해석 품질은 실제 유효 API 키로 추가 확인해야 합니다. 일반 DOM만 읽으며 cross-origin iframe, 닫힌 shadow root, 모든 SPA 편집기를 지원한다고 보장하지 않습니다.

## 7. 에이전트 테스트

실제 네이티브 도구로 입력·스크롤·클릭 승인/거부·오래된 대상 거부·선택하지 않은 탭 거부·임의 코드/사설 URL 거부를 검사했습니다. 일반 입력/textarea는 승인과 DOM setter/event 경로를 확인했습니다.

**실제 React useEffect 문서로 이동하고 Google 검색을 실행했습니다.** 이 검사는 AI 응답을 사용하지 않은 실제 브라우저 도구 검사입니다.

모의 모델과 실제 TabManager로 도구 호출 왕복, 현재/전용 탭, 기존 활성 탭 유지, 로그인 대기/명시적 재개, 개별 중지, 중복 요청 방지, 같은 탭 잠금, 서로 다른 탭 2개 작업과 제3 작업 차단을 확인했습니다.

실제 AI가 자연어 요청을 계획하여 외부 사이트에서 끝까지 수행하는 전체 E2E는 미검증입니다. CAPTCHA·로그인·결제/비밀번호/파일 업로드는 수동 처리하며, 복잡한 웹앱 조작은 실패할 수 있습니다.

## 8. 보안 검증

- 별도 QA 애플리케이션에서 실제 비동기 safeStorage 저장/복호화, 파일 평문 부재, 워크스페이스별 키 분리/삭제 확인.
- 저장소 사용 불가를 모의한 경우 저장을 거부하고 평문 대체하지 않는지 확인.
- 실제 패키지의 OS crypto는 테스트 도구에서 실행 파일을 직접 띄우면 실패했습니다. macOS LaunchServices로 동일 앱을 열어 별도 probe 및 전체 UI를 다시 실행한 결과 **실제 암호화·복호화·파일 평문 부재·0600 권한·재시작 후 키 복원이 통과**했습니다. 최종 패키지 UI 검사는 OS cipher를 대체하지 않습니다. 소스 UI의 모의 cipher 검사와 구분합니다.
- 알려진 키/토큰/카드 숫자/연락처 필터, URL 쿼리/프래그먼트 제거, 캡처 확인, 동의 철회/취소 경계 적용.
- 허용된 최상위 로컬 chrome·일반 세션·대상 워크스페이스/탭을 검사. 페이지에 privileged bridge 없음, private IPC 거부 확인.
- 고정 공식 API URL·Node fetch·쿠키 미사용·redirect 거부. 일반 사이트/확장 webRequest 경로로 API 키가 나가지 않음.
- 중요/불확실 작업 승인, 입력한 내용 표시, 거부 반복 차단, protocol/public DNS 사전 확인과 현재 상태 재검증.
- 모델/페이지 출력이 임의 JS·셸·파일·쿠키 도구를 생성하지 못함. Prompt injection의 완전한 방지 또는 포괄적인 보안 인증은 아님.
- gitleaks 소스 검사에서 탐지된 secret 없음. 배포 의존성 npm audit 결과 0건. 개발/빌드 도구의 기존 권고는 별도입니다.
- 첫 GitHub CI는 보고서에 넣은 검사 로그 SHA-256 두 개를 API 키로 오탐하여 중단됐습니다. 실제 로그 해시와 일치함을 확인하고, 해당 과거 커밋/파일/줄 두 개의 fingerprint만 `.gitleaksignore`에 지정했습니다. 보고서 해시 표현도 정리했습니다. 규칙 전체나 파일 전체를 제외하지 않고 Git 기록을 보존했습니다.

기존 키체인 항목/보안 속성/인증서를 삭제하거나, Gatekeeper·암호화·샌드박스·TLS를 약화시키지 않았습니다.

## 9. 성능·메모리 검사

- AI 기본 비활성화, lazy renderer 모듈 및 메인 서비스, 사용하지 않을 때 provider 요청 없음.
- AI용 별도 상주 프로세스를 추가하지 않음. 웹 작업 탭은 요청한 경우에만 생성/준비.
- 스트리밍 전체 대화 재전송 대신 60ms 단위 델타, 기존 메시지 Markdown memoization, 닫힌 패널 구독 해제.
- 텍스트/이미지/대화/작업/단계/시간/미리보기 캐시 크기 제한과 취소/정리.
- 최종 소스 UI 모의 검사 한 실행의 working-set 합: 패널 열기 전 **433.4 MiB**, 후 **440.5 MiB**, 모두 **4개 프로세스**. 맥 패키지는 **456.1 → 462.9 MiB**, 모두 **4개 프로세스**였습니다. 공유 메모리가 중복 합산될 수 있고 실제 AI 사용/장시간/Chrome 비교 측정이 아닙니다.
- 기존 경량화 12개 시나리오와 20개 native 탭 생성/19개 정리 회귀 확인.

메모리 누수가 전혀 없거나 Chrome보다 빠르다고 판단할 자료는 없습니다.

## 10. 기존 브라우저 회귀

실행한 명령/검사: renderer TypeScript, Electron typecheck, build, navigation, tabs, core, runtime, lightweight, workspaces, extensions, settings.

설정은 AI 카테고리 추가로 기존의 고정 11개 검사를 12개로, 삭제했던 전역 번역 메뉴 검사와 새 opt-in AI 선택 메뉴 검사를 구분했습니다. **25개 설정 시나리오**가 통과했습니다. 데이터·권한·쿠키·북마크·다운로드·시크릿·테마·사이트 검사·재시작 복원을 포함합니다.

워크스페이스/확장 fixture 회귀는 통과했으나 일부 기존 확장 worker, 임시 프로필 정리 중 캐시/child 종료 경고는 남습니다. 모든 실제 확장과 사이트/하드웨어/장시간 사용을 전수 검사했다는 뜻은 아닙니다.

## 11. 미구현·미검증

- 실제 사용자 키로 세 제공자의 정상 응답·실제 한도 전환·이미지 AI·자연어 외부 에이전트 전체 E2E.
- 다른 사용자 기기·개발 실행 환경에서의 키체인 접근 및 정식 서명 업데이트 후 암호화 키 호환. 이 기기의 일반 패키지 실행은 통과했지만 모든 실행 환경을 보장하지 않습니다.
- 자동 비밀번호 입력, 결제 정보 입력, 파일 업로드/OS 인증 자동 처리. 사용자 수동 단계입니다.
- cross-origin iframe/닫힌 shadow root, 임의 사이트의 모든 위젯, 임의 스크립트·셸/파일 도구.
- Windows 빌드/실행, Developer ID 서명/공증, 새 공개 릴리스/업데이트 E2E. 이번 범위에서 진행하지 않았습니다.

## 12. 발견하고 수정한 문제

- 숨긴 QA 창에서 캡처 표면을 얻지 못함 → 표시된 실제 native surface로 캡처 검사.
- 왼쪽 resize handle이 4px overflow → hit area를 패널 안에 배치.
- 좌우 전환 시 폭이 같아 ResizeObserver가 위치 변화를 놓침 → layout 변경 시 viewport 재보고.
- 설정과 AI를 동시에 띄워 800px에서 너무 좁아짐 → AI 설정 진입 시 패널 접기.
- Electron의 generic isolated-world 예외로 변경 상태를 구분하지 못함 → 제한된 오류 코드 envelope.
- 닫힌 UI 구독/전체 스트림 재전송/이전 Markdown 재파싱 → 구독 해제·델타·memoization.
- 키체인 접근 대기 → 제한된 대기와 명확한 오류. 직접 실행의 OS 접근 실패와 일반 앱 실행을 분리하고, LaunchServices의 실제 암호화·재시작 복원 검사로 확인. 기존 키체인 항목/ACL은 변경하지 않음.
- 모델별 함수 schema/생각 signature 및 없는 native 함수 ID, 부분 응답 후 전환, 거부 반복/동일 탭 경쟁/비동기 동의 변경 경계 보완.

## 13. 해결하지 못한 문제·배포 차단

테스트 도구에서 실행 파일을 직접 띄울 때 OS authorization 오류가 재현됩니다. 동일 맥 패키지를 LaunchServices로 열면 실제 키체인 및 재시작 복원이 통과했습니다. 실행 환경과 서명 identity의 영향으로 좁혔지만 OS 내부 실패 원인까지 증명한 것은 아닙니다. 원래 키체인 항목·ACL·저장 identity를 변경하지 않았습니다. [Electron 공식 문서](https://www.electronjs.org/docs/latest/api/safe-storage)는 macOS 키체인에 일관된 코드 서명을 권장합니다.

유효한 API 키가 없어 정상 생성 요청과 실제 AI 에이전트의 판단/품질을 확인하지 못했습니다. 서명/공증 인증 정보도 없습니다. 따라서 **일상 사용자에게 AI 안정판으로 배포할 준비가 됐다고 판정하지 않습니다.**
