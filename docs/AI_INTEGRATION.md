# NULL AI 개발판

소스 개발 버전: **1.1.0-beta.4**. 기존 공개 `1.0.1-beta.3`에는 아래 기능이 없습니다. 실제 Gemini 연결의 YouTube 열기 흐름을 확인했으며, 다른 제공자·이미지·한도·복잡한 작업의 실제 검증은 남아 있어 안정판 완료로 분류하지 않습니다.

## 사용 준비

1. 설정 → **NULL AI**에서 제공자를 고르고 API 키를 연결합니다. 여러 제공자를 등록할 수 있지만 한 번에 한 제공자의 연결만 표시합니다.
2. Gemini/Groq는 무료 계정 여부를 확인합니다. 연결 성공 시 에이전트가 켜집니다.
3. **페이지 데이터 전송 동의**를 직접 켭니다. 키는 채팅·Git·보고서에 붙이지 않고 앱 입력창에서만 관리합니다.
4. 툴바 말풍선을 열어 작업을 입력합니다. 항상 에이전트로 실행하며 모델은 입력창 아래에서 선택합니다. 저장한 연결은 패널을 열 때 다시 확인하므로 재시작마다 모델 갱신을 누를 필요가 없습니다.

기본 설정은 API 연결·에이전트 모델·사용/데이터 동의·전체 허용입니다. 전체 허용은 기본으로 켜지며 사이드바 입력창 위에서도 현재 모드를 바꿀 수 있습니다. 위치·새 탭 작업·페이지 참조·다른 제공자 전환은 **추가 설정**에 접어둡니다. 폭은 사이드바 경계에서 조절합니다. 암호화 저장소가 거부되면 평문 대체 없이 오류를 안내합니다.

공식 키 발급: [Gemini](https://aistudio.google.com/api-keys), [Groq](https://console.groq.com/keys), [OpenRouter](https://openrouter.ai/settings/keys).

무료 모델은 계정 요금제와 다릅니다. 특히 Gemini/Groq 모델 API는 현재 계정의 실제 결제 상태를 입증하지 않습니다. 무료 모델/무료 요금제 선택이 모든 비용을 없앤다는 보장은 하지 않습니다. 외부 제공자의 저장·학습 정책도 NULL의 로컬 대화 삭제와 별개입니다.

## 사이드바와 대화

툴바 말풍선 아이콘으로 엽니다. 왼쪽/오른쪽, 280~640px 너비를 지원하며 좁은 창에서는 실제 표시 너비를 제한합니다. 경계 드래그나 키보드 방향키로 조절합니다. 페이지와 분할 뷰가 패널을 덮지 않도록 네이티브 viewport를 함께 조정합니다.

내 입력은 오른쪽의 반전된 말풍선과 “나” 표시, 답변은 왼쪽의 아이콘과 “NULL” 표시로 구분합니다. 사용자 입력은 원문으로, AI 답변은 Markdown으로 표시합니다. 이전 메시지를 읽으려고 위로 스크롤하면 진행 상황 갱신이 읽는 위치를 강제로 아래로 옮기지 않습니다. 새 메시지를 전송하면 최신 위치를 따라갑니다. Markdown·코드 복사·중지·새 작업을 지원합니다. API 스트림은 취소할 수 있지만 에이전트의 중간 잡담은 숨기고, 도구 실행 결과를 확인한 뒤 최종 답변을 표시합니다. 닫아도 메인 프로세스의 작업과 대화는 유지하고, 다시 열 때 최신 상태를 읽습니다. 닫힌 UI는 스트리밍 구독을 해제합니다. 대화는 프로세스 메모리에서만 유지하고 종료 시 삭제합니다. 키/AI 설정만 별도 저장하며 기존 브라우저 설정 백업에는 API 키를 넣지 않습니다.

## 무료 모델과 전환

- OpenRouter: 인증된 키 확인 + 공개 모델 API의 명시적인 0단가 입력/출력 및 추가 비용 필터. 요청에도 `max_price`의 prompt/completion/request/image 0, 내부 provider fallback 금지를 지정합니다.
- Gemini: 인증된 모델 목록과 공식 Standard 무료 가격표의 교집합. 이미지/도구 지원은 공식 모델 자료로 확인합니다.
- Groq: 인증된 활성 모델 목록과 공식 Free Plan 표의 교집합. 문서로 확인된 도구/이미지 기능만 노출합니다.
- 문서 접근이 거부될 때만 만료일이 있는 보수적인 검토본을 사용할 수 있습니다. 현재 검토본은 **2026-11-11 00:00 KST 만료**입니다. 만료 후에는 해당 확인본을 이용한 모델을 실행하지 않습니다. 개발자는 공식 자료를 재검토하여 갱신해야 합니다. 목록을 영구 고정하지 않습니다.
- 모델 조회 결과는 최대 24시간 동안 실행 대상으로 인정합니다. 지원 종료/목록 제외 모델은 실행할 수 없습니다.
- 자동 전환은 별도의 제공자 변경 동의 및 사용자가 정한 우선순위가 있어야 합니다. 명시적인 요청·토큰 한도 초과만 대상이며 인증·크레딧·네트워크·서버·과부하 오류는 전환하지 않습니다.
- 응답 일부가 이미 출력된 뒤 오류가 나면 재실행하지 않습니다. 실행한 도구를 모델 변경으로 다시 실행하지 않고 관찰 결과만 이어 줍니다.

## 페이지 참조

기본 현재 탭이며 다른 탭은 사용자가 최대 3개까지 선택합니다. 선택한 지연 로딩 탭만 필요할 때 준비합니다. 다른 탭/워크스페이스를 일괄 로딩하거나 읽지 않습니다.

제목, 쿼리/프래그먼트를 제거한 URL, 크기를 제한한 텍스트·질문 관련 구간·제목 구조·코드·조작 가능한 요소를 수집합니다. 입력값·숨김 DOM·스크립트·스토리지·쿠키를 읽지 않습니다. 알려진 토큰/키/카드 숫자/이메일/전화번호를 필터링하고 로그인·결제 화면을 제한합니다. 개인정보 탐지의 완전성을 보장하지 않습니다.

이미지는 현재 페이지의 제한된 JPEG 캡처로 전달합니다. 입력 영역과 탐지된 민감 텍스트를 마스킹하고 페이지 변경을 재검사합니다. **전송 전 미리보기와 명시적인 확인**이 필요합니다. 모든 이미지 속 개인정보를 자동 식별한다는 뜻은 아닙니다. 텍스트 모델에서 이미지 전송은 차단됩니다. 이미지 파일 첨부나 cross-origin iframe 내부 수집은 구현 범위에 포함하지 않습니다.

선택 텍스트 우클릭에는 질문·설명·요약·번역이 있습니다. 사이드바에 질문을 준비하고 사용자가 전송합니다. 이전의 내장 번역 엔진·팔레트·광고차단을 복구하지 않습니다.

## 에이전트

에이전트 모드를 켜면 기본적으로 별도 탭에서 작업합니다. 설정에서 현재 탭 작업을 선택할 수 있습니다. 전용 탭은 생성 즉시 화면에 선택하고, 주소·제목·native view가 일반 주소창 이동과 같은 TabManager 경로로 함께 갱신됩니다.

허용 도구는 검색, 공개 URL 이동, 관찰한 링크 열기, 페이지 읽기, 스크롤, 요소 ID 기반 클릭·입력입니다. 임의 JavaScript/셸/파일 시스템/쿠키 도구는 없습니다. 입력은 비민감 일반 검색·텍스트·textarea·편집 영역만 대상으로 합니다. 일반 탐색·검색·입력·메뉴/탭/펼치기 등의 클릭은 작업 범위에서 매번 승인하지 않고 실행합니다. 새 공개 URL과 모델이 작성한 일반 검색어도 같은 정책입니다.

**전체 허용(기본)**에서는 사용자가 요청한 작업에 포함된 실행 가능한 클릭·입력·제출·주소 이동의 승인창을 건너뜁니다. 이름 없는 버튼이나 쓰기 양식도 같은 실행 모드를 따릅니다. 작업 중 전체 허용으로 바꾸면 대기 중인 동작 승인도 이어서 처리합니다. **중요 작업 확인**으로 바꾸면 상태 변경 주소, 전송·삭제 등의 클릭, 쓰기 양식과 판별하기 어려운 버튼을 개별 확인합니다. 거부한 같은 클릭은 반복하지 않습니다. 전체 허용도 로그인·민감 화면·비밀번호/결제 필드·파일 선택/업로드·네이티브 인증·사설망·임의 스크립트 같은 도구 제한을 해제하지 않습니다.

탭 URL·사용자 조작 횟수·요소 fingerprint를 재검사합니다. 같은 페이지에서 버튼이 자동 갱신되면 이전 요소를 실행하지 않고 새 화면을 다시 읽습니다. 전체 허용에서는 사용자 조작이나 URL 변경에도 이전 동작을 실행하지 않고 최신 화면을 다시 읽어 작업을 이어갑니다. 중요 작업 확인 모드에서는 이런 변경에 일시정지하며, 로그인·민감 화면의 직접 처리 대기는 두 모드 모두 유지합니다. 사이드바는 한 번에 한 작업을 실행합니다. 내부 전역 최대 2개 작업과 동일 탭 잠금, 16개 모델 단계, 10분 작업 제한을 둡니다. 중지는 API 스트림·대기 승인·가능한 네이티브 이동을 취소합니다.

확인된 실제 페이지가 없으면 모델이 “열었다”고 답해도 완료 처리하지 않습니다. 첫 단계에는 실제 도구 호출을 요구하고, 간단한 사이트 열기 요청은 목적지 호스트도 확인합니다. 결과에는 실제 확인한 페이지 링크를 표시합니다. 이는 복잡한 모든 작업의 의미적 성공을 보장하는 판정기는 아닙니다.

페이지와 모델 출력은 신뢰하지 않으며 별도의 system 지시/허용 도구/탭 소유권/프로토콜/공개 주소 검사/승인 경계를 사용합니다. Prompt injection이나 임의 웹앱의 부작용을 완전히 방지한다는 인증은 아닙니다. 동적으로 변하는 편집기, iframe, CAPTCHA, 사이트별 복잡한 작업은 실패하거나 수동 처리가 필요할 수 있습니다.

## 개발 실행과 검사

```sh
npm run build
npm run test:ai
npm run test:ai:ui
npm run package:mac
NULL_AI_PACKAGED=true node scratch/verify-ai-ui.cjs
node scripts/open-ai-preview.cjs
```

미리보기 실행기는 `tmp/ai-preview-profile`이라는 별도 프로필을 사용하고 기존 설치 앱과 실제 계정 데이터를 교체하지 않습니다. QA에서만 소유한 프로세스의 inspector와 모의 transport를 사용합니다. 제품 실행에는 디버깅 포트나 mock이 들어가지 않습니다.

실제 Gemini 연결의 사이트 열기와 완료 답변은 확인했습니다. 나머지 제공자 유효 키, 실제 사용 한도, 이미지 이해 결과, 복잡한 외부 사이트 에이전트는 검증해야 합니다. macOS 패키지는 일반 앱 실행 방식(LaunchServices)에서 실제 키체인 암호화·재시작 후 키 복원을 확인했습니다. 패키지 UI 검사는 모의 provider만 사용하며 OS 암호화는 대체하지 않습니다. 테스트 도구에서 실행 파일을 직접 spawn하면 키체인 거부가 재현되었습니다. 개발 실행의 OS 접근 상태가 다를 수 있으며, API 키를 평문으로 저장하거나 기존 키체인 ACL을 변경하지 않습니다. 정식 배포에는 일관된 Developer ID 서명·공증이 여전히 필요합니다.

공식 자료: [Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage), [Gemini API](https://ai.google.dev/api/generate-content), [Gemini 가격](https://aistudio.google.com/docs/pricing), [Groq API](https://console.groq.com/docs/api-reference), [Groq 한도](https://console.groq.com/docs/rate-limits), [OpenRouter API](https://openrouter.ai/docs/api_reference/overview), [OpenRouter 가격 상한](https://openrouter.ai/docs/guides/routing/provider-selection#max-price).
