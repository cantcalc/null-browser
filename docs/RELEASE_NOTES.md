# NULL Browser 테스트 배포

첫 NULL 공개 배포입니다. 버전은 Release 태그 및 설치 파일에 표시됩니다.
이 릴리스는 **Pre-release**이며 안정판으로 검증되지 않았습니다.

## 주요 기능

- Chromium/Electron 기반 탐색, 탭, 북마크·기록·다운로드, 분할 보기.
- 워크스페이스별 로그인·쿠키·사이트 데이터 분리. 북마크·기록·설정은 공통.
- 다크/화이트 테마, 탭 인터페이스 5종과 검색 홈 5종의 독립 선택.
- 별도 시크릿 세션과 보라색 홈.
- Chrome 웹 스토어 설치 경로 및 일부 확장의 동작 보완. 모든 Chrome 확장 호환을 보장하지 않음.

## 다운로드와 설치

- **macOS Apple Silicon arm64:** DMG를 열고 NULL.app을 Applications로 복사합니다. ZIP은 압축을 풀어 앱을 복사합니다. 기존 앱은 먼저 종료하세요.
- **Windows x64:** NULL-Setup EXE를 실행하고 설치 위치를 선택합니다. Windows 설정의 앱 제거 또는 제공된 제거 프로그램으로 삭제합니다.
- 설치 파일의 SHA-256은 `SHA256SUMS.txt`, 빌드 커밋과 파일 무결성은 `artifact-manifest-*.json`에서 확인합니다.

## 서명·공증과 검증 범위

- 현재 인증서가 제공되지 않은 빌드는 macOS 로컬 ad-hoc 서명이며 **Apple Developer ID 서명/공증이 아닙니다**. Gatekeeper가 실행을 차단할 수 있습니다.
- Windows 인증서가 없으면 Authenticode 미서명입니다. SmartScreen 경고가 나타날 수 있습니다.
- 실제 빌드별 상태는 `signing-status-*.json`에 기록합니다. 인증서가 없는데 서명/공증 완료로 보고하지 않습니다.
- CI smoke는 격리된 프로필에서 실행·로컬 페이지 로딩·설정 저장·종료/재실행을 검사합니다. Windows에서는 무인 설치·제거도 검사합니다. 모든 소비자 PC의 대화형 설치/DRM/GPU/보안 경고 처리 검증을 뜻하지 않습니다.

## 자동 업데이트

제공자는 **cantcalc/null-browser**입니다. 앱 시작 확인, 수동 확인, 사용자가 누르는 다운로드와 진행률, 재시작 설치 UI를 유지했습니다.

- beta 버전은 Pre-release 업데이트를 확인합니다. 기존 Aero/로컬 1.0.0은 이전 저장소를 바라보므로 이 설치본으로 한 번 수동 교체해야 새 저장소를 사용합니다.
- macOS ZIP과 플랫폼별 메타데이터를 함께 제공합니다. 파일 SHA-512와 실제 설치 파일의 일치를 검사합니다.
- **macOS 자동 설치는 배포 서명 조건이 충족되지 않아 보장하지 않습니다.** 메타데이터 제공과 실제 재시작 설치 성공은 별개입니다.
- 새 버전 업데이트 설치 E2E가 완료되지 않았다면 완료로 해석하지 마세요.
- 기존 Aero 저장소 및 배포 파일은 변경하지 않았습니다.

## 알려진 제한

- Chrome 확장 API 전체, 특히 세부 권한 회수 및 일부 고급 캡처/스크립트 기능은 제한됩니다. 확장 자동 업데이트는 꺼져 있습니다.
- 무거운 탭을 많이 사용하면 메모리가 증가합니다. Chrome보다 빠르거나 가볍다는 비교 인증은 없습니다.
- Google/OAuth 전체 로그인 경로, 모든 확장, 장시간 실사용 안정성, 모든 하드웨어는 검증하지 않았습니다.
- 개발·빌드 도구의 미해결 moderate 보안 권고는 `docs/SECURITY_REVIEW.md`에 기록합니다.
- 사용자 프로필·쿠키·워크스페이스 저장 경로 및 암호화 식별자는 기존 데이터 호환을 위해 유지합니다. 설치 전 중요한 데이터의 백업을 권장합니다.
