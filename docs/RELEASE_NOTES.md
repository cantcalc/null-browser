# NULL Browser 1.1.0-beta.1 — AI 실험판 배포 설명 초안

이 문서는 다음 배포를 위한 초안입니다. **현재 이 버전의 GitHub Release는 공개하지 않았습니다.** 기존 공개 다운로드는 1.0.1-beta.3입니다. Windows 작업은 보류합니다.

## 변경 사항

- Gemini / Groq / OpenRouter BYOK 연결, 확인된 무료 모델 선택과 사용자 우선순위의 한도 초과 전환.
- 좌/우·크기 조절 AI 사이드바, 스트리밍, Markdown/코드, 메모리 대화.
- 동의 기반 현재/선택 탭 분석, 선택 텍스트 질문·설명·요약·번역, 마스킹 캡처 확인 후 전송.
- 전용/현재 탭 에이전트, 제한된 탐색·읽기·클릭·입력, 승인·로그인 대기·중지, 최대 2개 작업과 탭 잠금.
- 기존 일반 브라우징·워크스페이스·시크릿·확장·테마·데이터 식별자 유지. AI는 시크릿에서 차단하고 기본 비활성화.

## 검증 범위와 남은 조건

실제 Electron 네이티브 검사 및 모의 provider를 연결한 실제 UI 검사 결과는 [AI 보고서](AI_IMPLEMENTATION_REPORT_2026-11-04.md)에 기록합니다. 실제 React 문서·Google 검색 탐색과 잘못된 API 키 거부를 확인했으나, **유효한 키를 이용한 AI 응답·실제 한도·실제 AI 이미지 이해·복잡한 외부 사이트 작업은 미검증**입니다.

별도 QA 앱뿐 아니라 맥 패키지를 일반 앱 실행 방식(LaunchServices)으로 열어 실제 비동기 OS 암호화·재시작 후 키 복원을 확인했습니다. 테스트 도구의 실행 파일 직접 실행에서는 키체인 거부가 재현됩니다. 평문 저장이나 기존 키체인 ACL 변경으로 우회하지 않습니다. 실제 유효 키로 AI 응답을 검증하지 못했으므로 **일반 사용자용 AI 안정판 준비 완료 상태가 아닙니다.**

Apple Developer ID 서명·공증 인증 정보가 없어 로컬 ad-hoc 서명만 사용합니다. Gatekeeper 및 업데이트 설치 제약은 유지됩니다. 업데이트 제공자는 cantcalc/null-browser이며 기존 Aero 저장소와 공개 Release는 변경하지 않았습니다.

공식 문서 접근 장애 시 쓰는 일부 무료/기능 확인본은 2026-11-11 00:00 KST에 만료합니다. 공식 자료 재검토가 필요합니다. 무료 모델 선택이 계정 비용 0을 보장하지 않습니다.
