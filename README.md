# Aero Browser

Aero is an Electron/Chromium-based desktop browser with native
`WebContentsView` tabs, workspaces, privacy controls, translation tools, and
cross-platform packaging.

## Development status

Release Candidate / active development.

## Supported build targets

- macOS arm64
- Windows x64

Unsigned builds are for testing only. Windows runtime verification, code
signing, notarization, and public GitHub Releases are separate release steps.
